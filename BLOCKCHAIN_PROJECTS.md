Comprehensive cryptocurrency card platform enabling users to pay, travel, send money across borders, and manage crypto seamlessly.

## 🔄 Updating Project Information

To update blockchain project information:

1. Edit `src/components/Portfolio.jsx`
2. Locate the `projects` array
3. Update the blockchain project objects (id 1-5)
4. Modify:
   - `title` - Project name
   - `description` - Brief description
   - `technologies` - Array of technologies
   - `details.fullDescription` - Complete description
   - `details.highlights` - Array of key features
   - `image` - Project image URL
